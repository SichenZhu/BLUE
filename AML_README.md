# AML Deconvolution Pipeline

## Preprocessing pipeline
**Step 1**: preprocess AML raw data from text files (downloaded from GEO databse with ID: GSE199336) to .h5ad file before input to the deconvolution pipeline. The annotated cell type can be downloaded from the supplementary table in the original paper: https://www.nature.com/articles/s41591-022-01819-x#Sec44 .

Run the conversion script:

```bash
uv run python scripts/dataset_specific/aml_txt_to_h5ad.py \
    --data-dir path/blue/AML_data \
    --out-dir  path/blue/AML_data/AML_h5ad/
```

_Inputs_:  per-patient `<patient>-D0.dem.txt` (genes × cells raw counts) and `<patient>-D0.anno.txt` (cells × metadata, must contain `CellType` column).
_Outputs_: per-patient `<patient>.h5ad` files with `.X` = raw counts, `obs["CellType"]`, `obs["library_id"]`, gene-symbol `var_names`.

**Step 2**: preprocess the TCGA-LAML bulk RPKM matrix (or raw counts matrix, the results won't differ too much. Both can be downloaded from https://gdc.cancer.gov/about-data/publications/laml_2012) into the default TSV format expected by the deconvolution pipeline (genes × samples, first column = `gene_id`). The script also reports the number of genes shared with the single-cell reference and warns if the overlap is below `--min-common-genes` (default 5000).

```bash
uv run python scripts/dataset_specific/aml_tcga_bulk_to_tsv.py \
    --bulk-txt path/blue/AML_data/TCGA-LAML_rpkm_matrix.txt \
    --sc-h5ad  path/blue/AML_data/AML_h5ad/AML210A.h5ad \
    --out-tsv  path/blue/AML_data/TCGA-LAML_bulk.tsv
```

_Inputs_:  raw TCGA RPKM matrix (`GeneID` column has form `SYMBOL|ENTREZ_calculated`); a representative sc h5ad to read gene symbols from.

_Outputs_: `TCGA-LAML_bulk.tsv` (17,948 genes × 179 samples) with `?`-annotated rows dropped, gene symbols extracted, and duplicate-symbol rows averaged.

## Deconvolution pipeline

All steps below read `config/pipeline_config_aml.yaml` and `config/celltype_mapping_aml.yaml`. Six malignant `*-like` cell types are kept; normal hematopoietic labels are NOT included in the deconvolution.

### Step 00 — combine per-patient sc h5ads into one labeled reference

```bash
uv run python scripts/deconv/00_combine_sc_h5ads.py --config config/pipeline_config_aml.yaml
```

_Output_: `path/blue/AML_output/processed_data/combined_labeled.h5ad` (11,641 cells × 27,899 genes; 6 coarse cell types).

### Step 01 — build common-gene and DEG lists

```bash
uv run python scripts/deconv/01_build_gene_lists.py --config config/pipeline_config_aml.yaml
```

_Outputs_ (in `path/blue/AML_output/deconv_training_data/`):
- `all_common_gene_lst.txt` — genes shared between sc reference and bulk TSV
- `all_DEG_lst.txt` — DEGs (per-patient one-vs-rest Wilcoxon, FDR < 0.1, deduplicated, intersected with common genes)

### Step 02 — simulate pseudobulks

```bash
uv run python scripts/deconv/02_simulate_pseudobulk.py --config config/pipeline_config_aml.yaml
```

_Outputs_ (in `path/blue/AML_output/deconv_training_data/pseudobulks/`):
- per-patient `<lib>_trainbulk.h5ad` and `<lib>_valbulk.h5ad`
- pooled `all_trainbulk.h5ad` (all patients' cells mixed) and `all_valbulk.h5ad` (all patients' cells mixed)
- pseudobulks generated by Dirichlet mixing.

### Step 03 — preprocess real bulk

```bash
uv run python scripts/deconv/03_preprocess_bulk.py --config config/pipeline_config_aml.yaml
```

_Output_: `path/blue/AML_output/deconv_training_data/bulk_preprocessed.h5ad` (179 TCGA samples × 17,948 common genes; libsize-normalized → ×1e6 → log2(+1)).

### Step 04 — train UNet

```bash
uv run python scripts/deconv/04_train_unet.py --config config/pipeline_config_aml.yaml
```

_Outputs_ (in `path/blue/AML_output/deconv_ckpt/<YYYYMMDD_HHMMSS>/`):
- `params.json` — hyperparameters and split metadata for the run
- `model_epN.pth` — checkpoint saved each epoch where val loss improved 
- `loss_history.csv` — per-epoch train and val losses

### Step 05 — predict on real bulk

```bash
uv run python scripts/deconv/05_predict_bulk.py --config config/pipeline_config_aml.yaml
```

(auto-finds the latest `<YYYYMMDD_HHMMSS>` checkpoint dir and the highest-epoch `model_ep*.pth`; pass `--ckpt /path/to/model_epN.pth` to override).

_Outputs_ (in `path/blue/AML_output/deconv_predictions/<YYYYMMDD_HHMMSS>/`):
- `predicted_proportions_epN.csv` — 179 TCGA samples × 6 cell-type fractions (sums to 1 per sample)
- `predicted_ctGEP_epN.h5ad` — predicted per-cell-type gene expression (one layer per cell type, over the 1,539 DEGs)

### Step 06 — visualize predictions on training/validation pseudobulks

```bash
uv run python scripts/deconv/06_visualize_predictions.py --config config/pipeline_config_aml.yaml
```

(auto-finds the latest run + best ckpt, reads `ctlist`/`deg_path`/`pseudobulk_dir` from that run's `params.json`).

_Outputs_ (in `<ckpt_dir>/viz/`): 
- `val_prop.png` & `val_GEP.png`: prediction vs. ground truth for validation samples
